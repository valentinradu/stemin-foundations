---
title: Direct current from the same machine
---

::: card
A spinning coil can only make alternating current; the cutting reverses every half turn, so the
raw output always alternates. A DC generator is the same machine with one addition: a
**commutator**, a split ring with sliding contacts that flips the connection to the outside world
every half turn, just as the voltage is about to reverse, so the terminals always see the same
polarity.
:::

::: card
The result is a bumpy one-directional voltage, smoothed toward flat by using many coils set at
staggered angles. The AC and DC generators share identical physics; they differ only in how the
output is tapped. Modern machines often generate AC and convert it to DC with diodes instead,
skipping the wearing brushes.
:::

::: exercise q1
What single part turns an AC generator into a DC one, and what does it do?

::: answer
A commutator, a split ring with sliding contacts. It flips the connection every half turn, just
as the voltage would reverse, so the terminals keep one polarity.
:::
:::
