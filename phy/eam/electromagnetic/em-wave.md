::: card
With the symmetry complete, something new becomes possible. A changing E creates B. That B is
changing too, because the E that made it is oscillating. That changing B creates E a little
further out, which creates B further still. Each field generates the next.
:::

::: card
The disturbance propagates outward through empty space, carrying itself, with no charge or wire
required. This is an electromagnetic wave. The two fields oscillate at the same frequency, in
phase, each perpendicular to the other and both perpendicular to the direction of travel.
:::

::: card
The speed at which this leapfrog propagates is set by how strongly each field responds to a
change in the other, which is exactly what $\varepsilon_0$ and $\mu_0$ measure.[wave speed](reference:wave-speed)

$$ c = \frac{1}{\sqrt{\varepsilon_0 \mu_0}} $$
:::

::: card
Maxwell calculated this from constants measured with torsion balances and current-carrying
wires, with no reference to light, and got $3 \times 10^8$ m/s. The speed of light had been
measured independently. They matched. Light is an electromagnetic wave, not similar to one but
identical.
:::

::: exercise q1
What sets the speed of an electromagnetic wave through empty space?

::: answer
The two constants $\varepsilon_0$ and $\mu_0$, through $c = 1/\sqrt{\varepsilon_0 \mu_0}$: how
strongly each field responds to a change in the other.
:::
:::

::: reference wave-speed
# Speed of an electromagnetic wave

A self-sustaining electromagnetic wave travels through empty space at a speed set by how strongly
each field responds to a change in the other.

Maxwell computed this from electrical constants alone and got the measured speed of light, which
revealed light to be an electromagnetic wave.

::: equation
c = \frac{1}{\sqrt{\varepsilon_0 \mu_0}} \qquad c^2 = \frac{1}{\varepsilon_0 \mu_0}
:::

::: legend
$c$: speed of light, in metres per second
$\varepsilon_0$: permittivity of free space
$\mu_0$: permeability of free space
:::
:::
